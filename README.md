# Git Secret Hunter & AI API Key Auditor

Сверхбыстрый сканер репозиториев Git для обнаружения уязвимостей, утечек API-ключей нейросетей, облачных токенов и случайных секретов с высокой энтропией Шеннона. Включает автономный модуль массового аудита репозиториев GitHub и интерактивный терминальный интерфейс (TUI).

## Возможности

- Анализ всей истории Git: все ветки (`--all`), теги, `reflog`, а также висячие/удаленные коммиты (`dangling commits`).
- Оптимизированный поиск добавленных строк: проверяются только реальные изменения (`diff -U0`), без траты ресурсов на неизмененный код.
- Параллелизация с помощью Rayon: максимальное использование всех ядер CPU.
- Zero-allocation энтропия: расчет энтропии Шеннона со стековым распределением частот байт и разверткой циклов без выделения кучи.
- Контекстный эвристический скоринг: анализ окружения токена, автоматическое определение уверенности (HIGH, NORMAL, LOW) и отсеивание mock/fixture данных.
- Интерактивный TUI-режим на Ratatui: навигация по найденным утечкам стрелочками, инспектор метаданных и возможность помечать секреты как разрешенные.
- Автоматический краулер GitHub: массовый аудит публичных репозиториев с выводом сводной аналитики.
- Маскирование секретов в консоли для безопасности отображения.
- Поддержка интеграции в CI/CD и Pre-commit хуки (возврат кода `1` при обнаружении утечек, поддержка JSON).

## Поддерживаемые сигнатуры

### Ключи искусственного интеллекта и нейросетей:
- OpenAI (`sk-proj-...`, `sk-admin-...`, `sk-...`)
- Anthropic Claude (`sk-ant-api03-...`, `sk-ant-admin01-...`)
- Google Gemini / Google AI Studio (`AIzaSy...`)
- DeepSeek API (`sk-[a-f0-9]{32}`)
- Together AI (`[a-f0-9]{64}`)
- Hugging Face User Access Tokens (`hf_...`)
- Replicate API (`r8_...`)
- Groq Cloud API (`gsk_...`)
- OpenRouter API (`sk-or-v1-...`)
- Perplexity AI (`pplx-...`)
- Cohere AI API
- Mistral AI API

### Облачные токены и авторизация:
- AWS Access Key ID (`AKIA...`, `ASIA...`)
- GitHub Personal Access Tokens (`ghp_...`, `github_pat_...`)
- GitLab Personal Access Tokens (`glpat-...`)
- JSON Web Tokens (JWT)
- Приватные RSA, EC, DSA, OPENSSH ключи
- Slack Bot/User Tokens (`xoxb-...`, `xoxp-...`)
- Stripe Secret Keys (`sk_live_...`, `rk_live_...`)

### Анализ энтропии Шеннона:
- Автоматический расчет энтропии $H \ge 4.5$ для нахождения случайных токенов без стандартных префиксов.
- Фильтрация ложных срабатываний (UUID, хэши Git коммитов, placeholder-значения).

## Использование CLI

```bash
# Базовое сканирование текущего репозитория
cargo run --release

# Интерактивный TUI режим (навигация стрелочками, инспектор)
cargo run --release -- --tui

# Сканирование конкретного каталога
cargo run --release -- --path C:\path\to\repo

# Поиск только API-ключей нейросетей
cargo run --release -- --ai-only

# Поиск только по точным сигнатурам (без анализа энтропии)
cargo run --release -- --no-entropy

# Вывод в формате JSON (для CI/CD)
cargo run --release -- --format json

# Сканирование только подготовленных изменений (Pre-commit hook)
cargo run --release -- --staged

# Массовый аудит 100 случайных публичных репозиториев GitHub
cargo run --release -- --crawl --crawl-limit 100 --crawl-depth 10

# Поиск и аудит репозиториев по ключевым словам или теме
cargo run --release -- --crawl --query "language:python ai bot" --crawl-limit 50
```

## Управление в TUI режиме

- `↑` / `k` — Предыдущая найденная уязвимость
- `↓` / `j` — Следующая найденная уязвимость
- `Space` / `m` — Переключить статус (RESOLVED / ACTIVE RISK)
- `q` / `Esc` — Выход из TUI
